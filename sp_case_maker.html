浏览器不支持

本工具用了现代浏览器的能力（目录写入、ES6、原生 dialog），IE / 旧版 Edge 无法运行。

请用 Microsoft Edge 或 Google Chrome 打开本文件。

请选择SP模板

填参数 → 生成 case 同名 .sp 文件（search / inc / param / temp / tran 整体替换，其余原样保留）
仅支持 Edge / Chrome
!
本工具仅在 Microsoft Edge 或 Google Chrome 下正常工作（Chromium 内核）。其他浏览器（尤其是 IE / 旧版 Edge） 不支持"选择输出文件夹并直接写入"，页面也可能无法正常渲染。若排版错乱或按钮无响应，请换用 Edge 打开。

也可以把 .sp 文件直接拖到页面任意位置。加载后自动解析模板里现有的 search / inc / param / temp / tran 并填入 Case 1。

未选择输出文件夹：将逐个下载到浏览器下载目录
