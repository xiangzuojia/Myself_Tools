如何添加新工具
  1. 所有工具都放进仓库的 tools/ 文件夹（index.html 自己留在根目录）。
  2. 单文件工具直接传成 tools/xxx.html；带 js / css / 图片的，在 tools/ 里再建子文件夹，主文件命名为 index.html。
  3. 打开本文件，在底部 TOOLS 清单里加一行，href 写相对 tools/ 的路径。
  4. 提交后等 Actions 跑完（约 40 秒），浏览器按 Ctrl+F5 强刷。
{ title: "图片压缩", desc: "纯浏览器内压缩，不上传服务器", href: "compress/", tag: "小工具", icon: "image" },
